⚙️ One-time Setup Required

Before student data will appear here, you need to connect a Google Apps Script. This takes about 5 minutes and only needs to be done once.

  1. Go to script.google.com and click New Project
  2. Paste the code from google_apps_script.js (included in your download) into the editor
  3. Click Deploy → New Deployment → Web App. Set "Who has access" to Anyone
  4. Copy the Web App URL provided after deployment
  5. Open student_site.html and paste the URL into the SCRIPT_URL variable at the top of the JavaScript section
  6. Do the same in this file — paste the URL into the SCRIPT_URL variable below
  7. Re-upload both files to your hosting (Netlify/GitHub Pages) — that's it!
